# AI News Board

AI News Boardは、AI関連ニュースをRSSから取得し、日付ごとに確認できるニュースボードです。
Laravel、PostgreSQL、Dockerを使い、ニュースの取得・保存・表示・日付絞り込みまでを一つのアプリとして実装しています。

## 概要

AI関連ニュースは毎日更新されますが、RSSだけでは過去記事を長く追いにくく、日付ごとの振り返りもしづらいです。
このアプリでは、RSSから取得したニュースをDBに蓄積し、直近の記事を日付ごとに確認できるようにしています。

ポートフォリオとしては、単なる静的な一覧画面ではなく、以下の流れを意識して作成しています。

- 外部RSSからデータを取得する
- 取得したデータをDBに保存する
- 重複登録を防ぐ
- 新しく追加された記事だけを最新として扱う
- 保存済みデータを画面で見やすく表示する
- Dockerで再現しやすい開発環境にする

## 主な機能

- AIニュースRSSの取得
- 取得した記事のDB保存
- 重複記事の登録防止
- 最新記事の一覧表示
- 日付ごとの記事絞り込み
- 新規取得記事への最新ラベル表示
- 記事カード全体から元記事への遷移
- Docker起動時のRSS自動取得
- PostgreSQLによる記事データの永続化

## アプリ構成

```text
RSS Feed
   ↓
Laravel Command
   ↓
PostgreSQL
   ↓
Laravel Controller
   ↓
Blade View
   ↓
News Board UI
```

RSS取得処理はLaravelのArtisanコマンドとして実装しています。
Docker起動時にはschedulerサービスがRSS取得を一度実行し、その後スケジュール処理を待機します。

## データ取得の流れ

1. Dockerを起動する
2. schedulerサービスが起動する
3. `php artisan news:fetch` が実行される
4. RSSフィードから記事情報を取得する
5. URLを基準に既存記事との重複を判定する
6. 新規記事のみDBに保存する
7. 新規保存された記事に最新ラベルを付ける
8. 画面側で記事一覧として表示する

## 画面機能

トップ画面では、取得したAIニュースをカード形式で表示します。
記事カードにはタイトル、公開日、画像プレビューを表示し、カード全体をクリックすると元記事へ移動できます。

日付プルダウンを使うことで、保存済みの記事を日付ごとに確認できます。
デフォルトでは最新日のニュースを表示します。

## 起動方法

```bash
docker compose up -d
```

起動後、ローカル環境では以下のURLで確認できます。

```text
http://localhost:8000
```

`localhost` は実行しているPC自身を指します。
そのため、このURLは公開URLではなく、Dockerを起動したローカル環境で確認するためのURLです。

## RSS取得コマンド

手動でRSS取得を実行する場合は、以下のコマンドを使用します。

```bash
php artisan news:fetch
```

Dockerコンテナ内で実行する場合は、以下のように実行します。

```bash
docker compose exec app php artisan news:fetch
```

## 工夫した点

### RSSをDBに蓄積する構成

RSSフィードは取得できる件数に限りがあります。
そのため、RSSを直接表示するだけではなく、取得した記事をDBに保存して蓄積できる構成にしています。

### 重複登録の防止

同じ記事が何度も保存されないように、記事URLを基準に重複判定を行っています。
これにより、定期的にRSS取得を実行してもDB内の記事が重複しないようにしています。

### 最新ラベルの管理

RSS取得時に新しく追加された記事だけを最新として扱います。
次回取得時に新しい記事が追加された場合は、その記事が新しい最新記事になります。

### Docker起動時の自動取得

Dockerを起動したタイミングでRSS取得が一度実行されるようにしています。
これにより、開発環境を立ち上げた時点で最新ニュースを取得しやすくしています。

### ポートフォリオとして見やすいUI

ニュース一覧は、単純なテーブルではなくカード型UIにしています。
画像プレビュー、ホバー表現、最新ラベル、日付絞り込みを組み合わせて、情報を見つけやすい画面を意識しています。
